| | |
|---|---|
| **Caso** | MineSight DD: pipeline de extracción + dashboard de KPIs de inversión minera |
| **Sistema** | (1) Descarga automática de informes → (2) Extracción y consolidación de KPIs → (3) Dashboard gerencial |
